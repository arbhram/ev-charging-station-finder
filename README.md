# EV Charging Station Finder

A MERN app for finding nearby EV charging stations and planning routes to your destination.

## Setup

**Backend**
```bash
cd ev-charging-app/backend
cp .env.example .env
npm install
npm run seed
npm run dev
```

**Frontend**
```bash
cd ev-charging-app/frontend
cp .env.example .env
npm install
npm start
```
