# EV Charging Station Finder

A MERN app for finding and planning routes to EV charging stations in Australia.

## Setup

**Backend**
```bash
cd backend
cp .env.example .env
npm install
npm run seed
npm run dev
```

**Frontend**
```bash
cd frontend
cp .env.example .env
npm install
npm start
```
